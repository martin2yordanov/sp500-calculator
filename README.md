# S&P 500 — Лихва върху лихва

Калкулатор за лихва върху лихва при периодични инвестиции в индексен фонд,
с живи цени на **SXR8** (iShares Core S&P 500 UCITS ETF, Xetra).

## Стартиране

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продукционен билд в dist/
```

`npm run dev` очаква `/api/sxr8` на `localhost:3000` (виж `vite.config.js`).
Най-лесно е с `vercel dev`, който вдига и статиката, и функцията заедно.

## Структура

| Път | Роля |
| --- | --- |
| `api/sxr8.js` | Vercel функция; проксира Yahoo Finance за `SXR8.DE` и връща `{ t, c }` точки |
| `src/App.jsx` | Основен изглед: статистики, прогнозна графика, контроли, месечна печалба |
| `src/components/Sxr8Chart.jsx` | Живата графика с обхвати 1D … Max |
| `src/lib/compound.js` | Месечно олихвяване; изчисленията са непроменени |
| `src/lib/settings.js` | Валидация на URL параметри и localStorage, граници на входните полета |
| `src/styles.css` | Дизайн токени и responsive стилове |
| `icons/app-icon.svg` | Мастер на иконката за приложението (с „500“) |
| `public/favicon.svg` | Мастер на favicon-а (без „500“) |
| `icons/generate.mjs` | Прегенерира растерните иконки от двата SVG-а |

## Иконки

Растерните файлове са комитнати, така че обикновен `npm install && npm run build`
не изисква нищо допълнително. Прегенерират се само при промяна на графиката:

```bash
npm i -D playwright && node icons/generate.mjs
```

**Два мастера, защото „S&P 500“ не се чете на всички размери:**

| Източник | Съдържа | Изход |
| --- | --- | --- |
| `icons/app-icon.svg` | линия със стрелка + площ + сияние + „S&P 500“ | 152 / 167 / 180 / 192 / 512 |
| `public/favicon.svg` | същата графика, без сияние и без надпис | таб иконката, и 16/32/48 в `favicon.ico` |

На 16px седем знака получават по около два пиксела всеки, затова надписът се
появява от 152px нагоре. Сиянието също е само в големите размери — на малките е
незабележимо, но продължава да отнема контраст по ръба на щриха.

Надписът е **истински текст, не пътища.** Това е безопасно само защото
`icons/app-icon.svg` никога не се сервира: генераторът го растеризира веднъж и
се качват PNG-тата. Сервираният `public/favicon.svg` не съдържа текст изобщо,
тъй че никой браузър не зависи от намирането на шрифт.

Прегенерирането иска **Liberation Sans** (Arial или Helvetica заместват
приемливо). Ако липсва, Chromium подменя безшумно и иконката излиза различна —
затова генераторът мери ширината на изчертания надпис и гърми при отклонение над
2%. `document.fonts.check()` не помага за това, връща `true` и за несъществуващо
име на шрифт.

Всеки размер, който iOS иска, се подава точно (152 / 167 / 180), за да няма
преоразмеряване на устройството — това е обичайната причина иконката на home
screen да излезе размазана. Графиката е квадратна без заоблени ъгли, защото iOS
налага собствената си маска.

Иконките не са обявени като `maskable` в манифеста: линията стига до ~86% от
широчината, което е малко извън безопасната зона от 80% при Android маската, и
краищата ѝ биха се отрязали.

## Запазване на настройки

Бутонът **Запази** кодира стойностите в URL (`?y=&m=&i=&r=`), копира линка и
пази копие в `localStorage`. При зареждане URL параметрите имат приоритет.
Стойности извън границите се ограничават, вместо да чупят изгледа.
