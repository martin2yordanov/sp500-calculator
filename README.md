# S&P 500 — Лихва върху лихва

Калкулатор за лихва върху лихва при периодични инвестиции в индексен фонд,
с живи цени на **SXR8** (iShares Core S&P 500 UCITS ETF, Xetra).

## Стартиране

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продукционен билд в dist/
```

`npm run dev` очаква `/api/sxr8` на `localhost:3000` (виж `vite.config.js`).
Най-лесно е с `vercel dev`, който вдига и статиката, и функцията заедно.

## Иконки

Растерните файлове са комитнати, така че обикновен `npm install && npm run build`
не изисква нищо допълнително. Прегенерират се само при промяна на графиката:

```bash
npm i -D playwright && node icons/generate.mjs
```

**Два мастера, защото „S&P 500“ не се чете на всички размери:**

| Източник | Съдържа | Изход |
| --- | --- | --- |
| `icons/app-icon.svg` | линия със стрелка + площ + сияние + „S&P 500“ | 152 / 167 / 180 / 192 / 512 |
| `public/favicon.svg` | същата графика, без сияние и без надпис | таб иконката, и 16/32/48 в `favicon.ico` |

На 16px седем знака получават по около два пиксела всеки, затова надписът се
появява от 152px нагоре. Сиянието също е само в големите размери — на малките е
незабележимо, но продължава да отнема контраст по ръба на щриха.

Надписът е **истински текст, не пътища.** Това е безопасно само защото
`icons/app-icon.svg` никога не се сервира: генераторът го растеризира веднъж и
се качват PNG-тата. Сервираният `public/favicon.svg` не съдържа текст изобщо,
тъй че никой браузър не зависи от намирането на шрифт.

Прегенерирането иска **Liberation Sans** (Arial или Helvetica заместват
приемливо). Ако липсва, Chromium подменя безшумно и иконката излиза различна —
затова генераторът мери ширината на изчертания надпис и гърми при отклонение над
2%. `document.fonts.check()` не помага за това, връща `true` и за несъществуващо
име на шрифт.

Всеки размер, който iOS иска, се подава точно (152 / 167 / 180), за да няма
преоразмеряване на устройството — това е обичайната причина иконката на home
screen да излезе размазана. Графиката е квадратна без заоблени ъгли, защото iOS
налага собствената си маска.

Иконките не са обявени като `maskable` в манифеста: линията стига до ~86% от
широчината, което е малко извън безопасната зона от 80% при Android маската, и
краищата ѝ биха се отрязали.

## Теми

Бутонът горе вдясно сменя тъмна/светла. Изборът се пази в `localStorage`; докато
няма избор, темата следва `prefers-color-scheme` и се мени заедно с него.

Токените живеят в `:root` (тъмна) и `:root[data-theme='light']` — сменят се само
цветове, нито едно правило за подредба не е дублирано. `index.html` слага
атрибута с вграден скрипт **преди** първото рисуване, иначе потребител със
светла системна тема виждаше тъмно проблясване, докато React се качи.

Две неща не са просто обръщане на стойностите:

- Lime `#e8ff5a` е невидим върху бяло, тъй че всичко, изчертано като текст или
  линия, минава на маслинено `#647700`. Яркият lime остава само като
  `--accent-solid` — фонът на бутона `Запази`, под почти черен текст.
- Тихите тонове са избрани чрез мерене, не на око: `--dim` и `--faint` дават
  6.56:1 и 5.17:1 спрямо фона, тъй че етикетите, подзаглавието и краищата на
  плъзгачите минават 4.5:1.

Цветовете на графиките са **дублирани в JS** (`CHART` в `src/lib/theme.js`).
Recharts пише `stroke` и `fill` като SVG атрибути, а там `var(--token)` не се
разрешава — само CSS свойства разрешават custom properties. Двете палитри трябва
да се държат в синхрон с CSS блоковете на ръка.

## iOS приложение (Capacitor)

Уеб приложението се опакова за App Store с [Capacitor](https://capacitorjs.com/)
— native Xcode проект в `ios/`, който зарежда локално вградения `dist/` build
вместо да го тегли от мрежата. Само живата цена на SXR8 минава по мрежа;
самият калкулатор работи изцяло offline.

```bash
npm run cap:sync      # build:native (абсолютен API адрес) + npx cap sync ios
npm run cap:open:ios   # горното + отваря Xcode
```

Пълният чеклист за подаване в App Store — bundle ID, provisioning, App Store
Connect метаданни, риска по Guideline 4.2 и какво изисква реален Mac — е в
[`ios/APP_STORE_CHECKLIST.md`](ios/APP_STORE_CHECKLIST.md).

**Защо `/api/sxr8` не е просто относителен път навсякъде.** На уеб Vercel
сервира и статиката, и функцията от един домейн, тъй че относителен път е
едновременно правилен и имунизиран към сочене към грешен deploy (preview вика
собствения си preview). Native обвивката няма такъв произход — Capacitor
сервира пакетирания `dist/` от `capacitor://localhost`, където няма backend.
`src/lib/api.js` решава това с една променлива, зададена само при native билд
(`VITE_API_BASE_URL`), не с if/else разклонение в компонента.

**Offline не е компромис, а функция.** Калкулаторът е чиста клиентска
математика — никога не е зависел от мрежа. Само живата графика на SXR8 го
прави, и сега пази последната успешна цена в `localStorage`
(`src/lib/priceCache.js`): при неуспешна заявка показва тази цена с амбър
банер „Няма връзка · последна известна цена преди Xм“, вместо гола грешка.
Обхват, който никога не е бил зареждан тази сесия и няма кеш, си показва
истинска грешка с бутон за повторен опит — не подменя тихо грешен диапазон.

**Иконата и launch screen** идват от `resources/icon-only.png` (1024×1024,
без alpha канал — Apple го изисква) и `resources/splash.png` (2732×2732,
графиката смалена до ~30% от широчината, центрирана). Смалена е нарочно:
`UIImageView.scaleAspectFill` показва само централните ~46% от широчината на
квадратно изображение на най-тесните iPhone екрани (проверено с реални
съотношения, не на око) — графика, изчертана до ръба, би се обрязала.
Прегенерират се с:

```bash
npm run assets:generate
```

Проектът е таргетиран само за iPhone (`TARGETED_DEVICE_FAMILY = "1"`) за по-
простото първо подаване — виж чеклиста как да добавиш iPad.

## Запазване на настройки

Бутонът **Запази** кодира стойностите в URL (`?y=&m=&i=&r=`), копира линка и
пази копие в `localStorage`. При зареждане URL параметрите имат приоритет.
Стойности извън границите се ограничават, вместо да чупят изгледа.
